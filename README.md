## 环境和启动

需要Docker Desktop、微信开发者工具；宿主机检查使用Node.js 24与pnpm。先确认Compose项目名、端口和数据卷归属；以下命令会写目标环境，只用于接手人新建的合成本地环境，不覆盖或复位既有共享/业务数据。

在项目根目录：

```powershell
if (-not (Test-Path -LiteralPath '.env')) {
  Copy-Item -LiteralPath '.env.example' -Destination '.env'
}
docker compose config --quiet
docker compose up -d --build
docker compose ps
docker compose exec -T backend pnpm --dir backend db:migrate:deploy
Invoke-RestMethod http://127.0.0.1:3000/health
```

健康接口应返回`data.status: ok`。确认这是专用Mock-auth开发库后，才准备演示数据：

```powershell
docker compose exec -T backend pnpm --dir backend db:prepare-recording-demo
```

准备脚本会复位固定合成记录，要求development、mock认证、本机/Compose PostgreSQL及`education_app`库；环境校验通过不表示任意库可复位。默认11账号、陈晨主课时900/赠送200均为内部课时单位；演示金额/政策不是正式制度。`postgres`使用持久卷，`postgres_test`是tmpfs，不能保存待交接数据。

## 必须保留的业务和工程边界

- 正式账号单角色，后端逐接口校验权限/校区/个人范围。普通运营恰好一个校区；总号无校区、逐区授权、只读聚合，不能读取个人档案或调用业务写入。隐藏按钮或前端参数不是鉴权。
- 金额用整数最小货币单位；金额/课时由后端计算，PostgreSQL是事实来源。变化追加账本，保留事务、幂等、适当锁/约束和回滚；余额非负，Redis不作事实来源。
- 完课后扣课，新扣课赠课优先，桶内沿现役顺序；撤销按原流水反向恢复。批准请假不等于最终出勤，教师显式点名为最终教学事实。未完课沿当前有效名单，终态沿保存名单，不用现在关系改历史。
- 临时成员只加本校区已有有效学员到未来课次，不永久入班、不预扣/预留；完课重新核余额及退费预留。周期排课以Asia/Shanghai解释，每周/每两周，必填起止日，同时不超过12周/50节；预览确认、冲突/版本重查、全成全败，取消范围明确，终态保留。
- 普通收款录包无需逐笔总端审核，一笔收款发包一次，主赠独立；无可靠原始实收/发包快照显示待核对，不从余额倒推。退费持久化预留、累计实退/预留不超实收、申请人不得自审；批准不是实际退款。
- 纠错保留原事实/反向流水/原因/审计，正式订单、账本、课时流水和审计不硬删除。版本化计费和历史快照保留，不追溯改收益；内部收益不自动等于可提现现金。人工/模拟提现不授权真实出款。
- 教师逐课四维、家长评价、合作方月评分别保留作者和有效/撤销语义；月榜保持独立指标及最小披露。家长仅绑定范围，首次资料完善不开放任意新增绑定、校区/课包修改。
- 未齐正式条件保持`PAYMENT_DRIVER=mock`并明确模拟，正式适配器fail-closed，到账不靠客户端回调。不启用真实中间账户、自动打款/分账、未批准商城/营销、完整工资/净利润或发布。免费活动第一增量只登记、不自动送课。
- 保持现有技术栈和适配器；接口先改OpenAPI/测试，结构变化带迁移。真实.env、Token、私钥、身份数据不入源码/Git。测试入口仅本地显式开启，Token只在本机education.runtime。
- 不批量删除用户文件或数据，不复位未知/共享库。主包仅bootstrap、普通角色分包，素材/字体上限不放宽。UI按对应原稿和真实数据核对，不拆人物、不用整页截图或示例照片/满星冒充业务。
